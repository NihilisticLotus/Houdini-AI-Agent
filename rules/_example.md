# Example User Rule

This file is an example/template for user-defined rules.

Files in the `rules/` directory with `.md` or `.txt` extension are
automatically loaded as file rules. Files starting with `_` are ignored.

## Tips

- Write rules in plain language, as if instructing an assistant.
- Be specific about preferences (node naming, VEX style, output format).
- Each file becomes one rule. The filename (without extension) becomes the rule title.
